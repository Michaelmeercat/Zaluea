# Riftkeepers

A colourful, mobile-friendly tower defense game. Small guardians protect floating islands from creatures
escaping unstable dimensional rifts. Place guardians beside the roads, upgrade them along three paths,
and survive increasingly clever waves.

Built with TypeScript + Canvas 2D (no game framework), plain HTML/CSS for menus, and Vite.
Everything — art, music and sound — is generated by the game's own code; there are no external
runtime requests, and the production build works offline as an installable PWA.

## Launch

Requires Node 18+ (tested on Node 22).

```bash
cd riftkeepers
npm install
npm run dev        # http://localhost:5173 (also reachable from a phone on the same network)
```

Production build:

```bash
npm run build      # typecheck + build to riftkeepers/dist
npm run preview    # serve the production build at http://localhost:4173
```

`dist/` is a static site: host it anywhere (it uses relative paths, so a sub-folder works).
`npm run build:site` also copies the build into the surrounding Zaluea site at `Site/games/riftkeepers/`,
where it appears in the site's Games list. `npm run build:artifact` produces a single self-contained HTML page
(`dist-artifact/riftkeepers.html`, fonts and code inlined, no service worker) for embedding in sandboxed viewers.

Tests:

```bash
npm test           # 74 unit tests (rules, economy, saves, determinism…)
npm run balance    # headless balance playtests with an automated player (slow, ~2–3 min)
```

## How to play

- **Play** → pick an island and difficulty (Easy 40 waves, Normal 60, Hard 80). New players are offered a short tutorial.
- Tap a guardian in the shop, tap/drag on green ground, then press ✓ (with a mouse a click places directly).
- Tap a guardian to select it: targeting mode, three upgrade paths, sell (70% refund).
- Press **Start Wave** (or Space). Speed 1×/2×/3× and auto-start are in the top bar.
- Abilities (Lyra's Rift Pulse / Time Anchor and tower actives) appear at the lower left of the battlefield.

Keyboard: `Space` start wave · `Esc` cancel/pause · `1`–`7` shop · `Tab` speed · `Q W E R T Y` abilities ·
`U I O` upgrade the selected guardian's paths · `S` sell.

## Contents

- 6 maps (Meadow Bend, Sunken Ruins, Twinroot Crossing, Frostglass Pass, Clockwork Market, Rift Citadel)
- 6 guardians × 3 paths × 5 tiers = 90 upgrades, plus the hero Lyra (10 levels, 2 abilities)
- 10 enemy families, 4 variants (concealed, regenerating, shielded, reinforced) and a 3-phase boss
- 80 authored waves + deterministic endless mode
- Campaign, Endless, Daily Challenge, 6 Restricted Challenges, Sandbox
- Rift Shards, unlocks, talents (modest; disabled in Pure mode), cosmetics, medals, 20 achievements
- Versioned local save with export/import, corruption recovery and mid-wave-safe continue

See `BALANCE.md` for balance decisions and `PROGRESS.md` for architecture notes.

## Project layout

```
src/core     RNG, math, shared types
src/data     towers & upgrades, enemies, maps, waves (authored DSL), hero, progression data
src/sim      deterministic fixed-step simulation (no DOM), placement, pathing, spatial grid
src/render   Canvas renderer, procedural art, sprite cache, particles
src/audio    WebAudio synthesized sound effects and music
src/save     versioned save, validation, import/export
src/game     game session (loop, input, HUD), panels, tutorial, progression rules
src/ui       app shell, screens, styles, icons
tests        vitest unit tests + balance playtests
scripts      Playwright verification scenarios, icon generator
```
